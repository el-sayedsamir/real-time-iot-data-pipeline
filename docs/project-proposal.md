# Project Proposal

## Project Name

Real-Time IoT Data Pipeline

## Project Overview

The project aims to build a data pipeline that simulates temperature and humidity sensor readings and processes them using batch and streaming techniques.

## Planned Objectives

- Simulate IoT sensor data using Python.
- Ingest and store sensor readings.
- Design a batch ETL pipeline.
- Explore real-time stream processing and alerting.
- Plan a dashboard for data visualization.
- Document the project design and implementation.

## Planned Milestones

1. Data Simulation and Ingestion
2. Batch Data Pipeline (ETL)
3. Streaming Pipeline with Alerts
4. Dashboard and Final Report

## Current Status

Initial planning and GitHub repository setup. Implementation has not started.

## Technical Decisions

The technologies and architecture will be selected during the planning phase.
